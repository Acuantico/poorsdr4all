# Filter Relays

Plugin de PoorSDR4All para seleccionar por banda un banco remoto de filtros
mediante relés WiFi.

Requiere PoorSDR4All 1.0.0a1 o posterior. Se instala desde el directorio del
plugin con:

```bash
python -m pip install .
```
